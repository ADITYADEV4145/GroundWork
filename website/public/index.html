A FEW GOOD QUESTIONS

Before you
dig in.

Is this a replacement for my coding agent?+

No. Groundwork works underneath Claude Code, Codex, and Cursor. It provides a codebase index, MCP tools, an agent skill, and hooks that help your existing agent work with better context.

Which languages does it understand?+

TypeScript, JavaScript (including JSX and CommonJS), and Python. Other files fall back to your agent’s normal tools.

Will it block or slow down my agent?+

Hooks usually answer in milliseconds and have a two-second limit. On an error or timeout, the agent continues. The standard profile guides; strict can block at Stop once for each new set of findings. Cursor cannot show nonblocking Stop warnings, so use strict or run gw check directly.

Does anything leave my machine?+

There is no telemetry or network access at runtime. Installation downloads dependencies. If you explicitly run gw init --embeddings, Groundwork downloads a model; inference then runs locally.

Can it catch every mistake?+

No. Grounding checks only calls it can resolve definitely, skipping dynamic dispatch, computed member names, and external packages. Duplicate detection is strongest for exact and renamed copies. It complements tests and review, not replaces them. Read the accuracy notes ↗

What if I want to remove it?+

Run gw setup --remove to undo the project setup, then delete .groundwork/. Setup preserves your existing agent settings.
