# README artwork

- `groundwork-hero.webp` and `groundwork-workflow.webp` are AI-generated brand illustrations, generated for this repository with OpenAI's image generation tool, then cropped, typeset and compressed to WebP. They are conceptual artwork, not product screenshots or measured results.
- `architecture.svg` is an editable, hand-authored diagram of the local architecture. Text equivalents for the diagrams appear in the project README.

All three assets are stored locally so the README does not depend on a third-party image host. The repository's MIT license applies.
